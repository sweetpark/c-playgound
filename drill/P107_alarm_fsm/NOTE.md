# NOTE · P107 alarm_fsm (풀고 난 뒤에 보세요)

**원본 글**: 「[모니터링] 알람 상태 머신 — 임계·히스테리시스·발생과 해제」 (학습 노트)

**함정 요약**
- 켜짐 쪽도 `value >= set` 기준으로 판단 — 완충 지대 값에서 상태가 바뀌어 히스테리시스가 사라진다. 켜짐 쪽은 `value < clear` 만 본다
- 연속 횟수를 **리셋하지 않음** — "연속 3번"이 "누적 3번"이 된다 (`95, 70, 95, 96` 에서 켜지면 틀림)
- 켜진 상태에서 초과가 계속될 때마다 `OCCURRED` 를 반환 — 알람 폭주. **상태가 바뀔 때만** 이벤트를 낸다
- 상태 전환 때 연속 횟수를 안 지움 — 지난번에 센 값이 남아 있어 **다음 켜짐/꺼짐에서 "연속 N회" 요구가 무시된다** (`[8]` 은 초과 쪽, `[9]` 는 정상 쪽)
- `alarm_create` 인자 검사 누락 — `clear > set` 이면 켜진 직후 바로 꺼져 버리는 알람이 생긴다
- `calloc` 실패 처리, `destroy(NULL)` 허용 — 방어 코드의 기본

**한 줄 설명 연습**: "임계 하나는 경계에서 깜박이고, 켜는 기준과 끄는 기준을 다르게(히스테리시스) 두고 연속 N회를 요구하면 안정된다. 대신 발생·해제가 그만큼 늦어진다." 를 내 말로 쓴다.
