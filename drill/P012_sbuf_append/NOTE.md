# NOTE · P012 sbuf_append (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[C] 동적 메모리 실습 — malloc·free 오류 패턴과 유연 배열 구조체 연결리스트」 §5 "직접 만들기 1 — realloc과 이중 포인터"
- 소스: [`c_basic/mem/mem_ex.c`](../../c_basic/mem/mem_ex.c)

**함정 요약**
- `realloc` 은 블록을 옮길 수 있다 → 값 전달 포인터를 갱신해도 호출자는 모른다 → **이중 포인터**(또는 반환값 사용). 옛 주소를 계속 쓰면 use-after-free.
- 반환값을 원래 포인터에 바로 대입하면 `NULL` 일 때 원본을 잃는다(누수). 임시 변수 → 검사 → 대입.
- 이어 붙일 위치는 `cap`(할당 크기)이 아니라 `len`. 초기 상태는 빈 문자열(`data[0] = '\0'`).
- 이 테스트는 `realloc` 을 가로채 실패를 주입한다 — 정상 경로만 돌리면 이 버그는 절대 안 보인다.

**한 줄 설명 연습**: "`realloc` 의 결과는 임시 변수로 받아 검사하고, 주소가 바뀌니까 호출자 포인터는 이중 포인터로 갱신한다."
