**함정 요약**
- `*` 하나만 블랙리스트로 막음 — LDAP 특수문자는 `* ( ) \ NUL` 다섯 개다.
- SD01의 SQL 필터 함수를 그대로 복사해서 예약어(`select` 등) 검사를 넣음 — LDAP은 SQL과 위험 문자 집합이 다르다.
- DN과 필터의 이스케이프 규칙을 혼동 — DN 특수문자(`\`)와 필터 특수문자(`= + < > # ; \`)는 서로 다르다(변형 C에서 필터 이스케이프만 다룬다)
