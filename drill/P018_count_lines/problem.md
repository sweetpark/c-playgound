# P018 · count_lines — fgets 조각과 EOF/오류 구분

## 요구사항
텍스트 파일의 **줄 수**를 센다. 줄 끝 개행을 본 것을 한 줄로 세고, 개행 없이 끝난 마지막 줄도 한 줄이다. 읽기 버퍼는 작게(16바이트) 잡아야 하며, 버퍼보다 긴 줄도 **한 줄**로 센다.
루프가 끝난 이유가 EOF 인지 읽기 오류인지 구분하고, 어느 경로에서든 파일을 닫는다.

## 시그니처
```c
long count_lines(const char *path);
/* >= 0 : 줄 수
 * -1   : path == NULL 또는 열기 실패
 * -2   : 읽는 도중 오류 (ferror)  */
```

## 입출력 예시
| 파일 내용 | 반환 |
|---|---|
| `"a\nb\nc\n"` | 3 |
| `"a\nb"` (마지막 개행 없음) | 2 |
| `""` | 0 |
| 100 글자 + `"\n"` | 1 (버퍼 16 으로 여러 번 읽어도) |
| 15/16/17 글자 + `"\n"` | 각각 1 (버퍼 경계) |
| 없는 파일 | -1 |
| 디렉터리 경로 (열리지만 읽기는 실패) | -2 |

## 제약
- `fgets` 가 `NULL` 을 돌려주는 이유는 두 가지다: EOF, 오류. `ferror(fp)` 로 구분한다.
- `fgets` 가 돌려준 조각 끝에 `'\n'` 이 있을 때만 줄 하나가 끝난 것이다.
- `fclose` 는 정상·오류 모든 경로에서. (누수 검출은 새니타이저가 아니라 습관.)
