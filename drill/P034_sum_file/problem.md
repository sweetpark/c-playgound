# P034 · sum_file — 읽기 루프 종료 이유와 에러 코드

## 요구사항
스트림에서 공백으로 구분된 `long` 정수를 끝까지 읽어 합을 구한다. 읽기 루프가 끝난 **이유**를 구분한다: 정상 EOF, 읽기 오류, 숫자가 아닌 토큰. 합이 `long` 범위를 넘으면 오류.

## 시그니처
```c
int sum_file(FILE *fp, long *out);
/* 0  : 성공, *out = 합 (빈 파일이면 0)
 * -1 : fp/out == NULL
 * -2 : 읽기 오류 (ferror)
 * -3 : 숫자가 아닌 토큰
 * -4 : 합 오버플로
 * 실패하면 *out 은 건드리지 않는다 */
```

## 입출력 예시
| 입력 | 결과 |
|---|---|
| `"1 2 3\n4"` | 0, 10 |
| `""`, `"  \n"` | 0, 0 |
| `"1 x 3"`, `"1 2 3abc"` | -3 |
| `"9223372036854775807 1"` | -4 |
| 쓰기 전용으로 연 스트림 | -2 |
| `NULL` | -1 |

## 제약
- `fscanf` 반환값: 1 = 읽음, 0 = 형식 불일치, EOF = 입력 끝 또는 오류. EOF 일 때 `feof`/`ferror` 로 정상 끝과 오류를 가른다.
- signed 오버플로는 UB 다 — 더하기 **전에** 검사하거나 `__builtin_add_overflow` 로.
- 진입부에서 NULL 검사.
