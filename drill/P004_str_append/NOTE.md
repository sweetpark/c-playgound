# NOTE · P004 str_append (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[C] 문자열 함수 실습 — strncpy·strncat 직접 구현과 오버플로 함정」 §5 "가장 흔한 실수: 루프 안의 strlen(dst)" 와 "고친 구현"
- 소스: [`c_basic/str/str_ex.c`](../../c_basic/str/str_ex.c) `my_strncat`

**함정 요약**
- 루프 안 `strlen(dst)` → 첫 글자를 쓰는 순간 길이가 변해 `"dsts"` 처럼 한 칸씩 건너뛴다(O(n²) 는 덤).
- 크기 검사는 `+ 1`(널 문자). `strlen(dst) + strlen(src) - 1` 처럼 `size_t` 를 빼면 언더플로.
- 실패할 거라면 `dst` 를 건드리지 않는다(검사 후 쓰기).
- `dst` 자체가 널로 끝나지 않을 수 있다는 방어(`strnlen`) — 원본 글에는 없는 보강.

**한 줄 설명 연습**: "길이는 쓰기 전에 한 번 구해 고정하고, 널 문자 자리까지 포함해 검사한 뒤에만 쓴다."
