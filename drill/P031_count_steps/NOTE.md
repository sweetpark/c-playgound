- 「[C] 바이트 순서·메시지 헤더·컴파일러 경고 실습 — htonll·enc_dec와 size_t·switch 함정」 "16-04 size_t i <= SIZE_MAX 가 항상 참 + i += step 랩어라운드 → 무한 루프", "16-01 size_t 로 enum 순회"
- 소스: [`c_basic/lecture/msc/16-04.c`](../../c_basic/lecture/msc/16-04.c)

**함정 요약**
- `size_t` 는 부호가 없어서 `i <= SIZE_MAX` 는 항상 참 → 종료 조건 자체가 없다. 더해서 넘치면 0 근처로 돌아가 영원히 돈다.
- 증가시킨 **뒤에** 검사하면 이미 넘친 값이다 → 증가시키기 전에 `end - i >= step` 인지 본다.
- 뺄셈은 큰 값에서 작은 값을 빼는 순서가 보장될 때만(`start <= end`).

**한 줄 설명 연습**: "부호 없는 정수는 넘치면 조용히 돌아가니까, 더하기 전에 남은 거리를 비교한다."
