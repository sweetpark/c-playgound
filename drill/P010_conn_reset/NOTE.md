**함정 요약**
- `memset(c, 0, sizeof(c))` → 포인터 크기(8바이트)만 지워지고 나머지는 쓰레기로 남는다. `sizeof(*c)` 또는 `sizeof(conn_t)`.
- `malloc(sizeof(c))` 도 같은 실수: 작게 할당하고 구조체를 쓰는 순간 힙 오버플로 (9-11).
- 필드별 대입으로 초기화하면 새 필드나 패딩이 빠진다. 구조체째 `memset` 한 뒤 0 이 아닌 값만 따로 설정.
- `fd = 0` 은 유효한 fd(표준입력)다. "닫힘" 표시는 `-1`.
- 배열 멤버(`host`)의 `sizeof` 는 배열 크기가 나온다(P002) — 포인터 멤버였다면 8.

**한 줄 설명 연습**: "크기는 포인터가 아니라 가리키는 대상에서 구한다 — `sizeof(*p)`."
