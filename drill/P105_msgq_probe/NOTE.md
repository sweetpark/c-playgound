# NOTE · P105 msgq_probe (풀고 난 뒤에 보세요)

**원본 글**: 「[C] 메시지 큐(System V) — 커널이 들고 있는 우편함」 (학습 노트, 블로그 게시 예정)

**함정 요약**
- `IPC_NOWAIT` 없이 `msgsnd` — 큐가 차면 호출이 **영원히 잠든다.** 장애 때 "프로세스가 멈췄다"의 흔한 원인
- `msgsnd` 길이에 `sizeof(struct)` 를 넘김 — `mtype`(8바이트)이 길이에 섞여 들어가 용량이 어긋나거나 `EINVAL`
- `mtype = 0` — `EINVAL`
- 용량을 **올리려고** `IPC_SET` — 특권이 없으면 `EPERM`. 이 문제는 줄이기만 한다
- `drain` 에서 `IPC_NOWAIT` 를 빼먹음 — 빈 큐에서 영원히 대기
- 큐를 안 지움 — 프로세스가 끝나도 큐는 남는다. `ipcs -q` 로 보이고, 쌓이면 `msgmni`(큐 개수 한도)를 다 쓴다. 정리는 `ipcrm -q <id>`

**한 줄 설명 연습**: "큐는 커널 것이라 받는 쪽이 죽어도 안 사라지고, 계속 쌓이다가 용량이 차면 보내는 쪽이 `EAGAIN` 을 받거나(NOWAIT) 잠든다(기본)." 를 내 말로 쓴다.
