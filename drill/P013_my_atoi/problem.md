# P013 · my_atoi — strtol 로 만드는 엄격한 정수 변환

## 요구사항
문자열 `s` 를 10진 `int` 로 변환한다. 숫자 **전체**가 변환돼야 한다(뒤쪽 쓰레기·앞뒤 공백 거절).
`int` 범위를 벗어나면 따로 구분되는 오류. 실패하면 `*out` 은 건드리지 않는다.

## 시그니처
```c
int my_atoi(const char *s, int *out);
/* 0  : 성공, *out = 값
 * -1 : 형식 오류 — NULL, "", 숫자 없음("abc", "-"), 뒤쪽 쓰레기("12a"), 앞뒤 공백, 0x 접두
 * -2 : 범위 오류 — int 범위 밖, 또는 long 범위 밖(ERANGE) */
```

## 입출력 예시
| `s` | 반환 | `*out` |
|---|---|---|
| `"123"`, `"-45"`, `"+7"`, `"007"` | 0 | 123, -45, 7, 7 |
| `"2147483647"`, `"-2147483648"` | 0 | `INT_MAX`, `INT_MIN` |
| `"2147483648"`, `"-2147483649"` | -2 | (변화 없음) |
| `"99999999999999999999"` | -2 | (변화 없음) |
| `"12a"`, `" 1"`, `"1 "`, `""`, `"-"`, `"0x10"` | -1 | (변화 없음) |
| `NULL` | -1 | (변화 없음) |

## 제약
- `atoi` 는 오류를 알려 주지 않으므로 사용 금지. `strtol` 을 쓴다.
- `strtol` 호출 **전에** `errno = 0`. (이전 호출이 남긴 `errno` 를 이번 오류로 오인하면 안 된다.)
- 64비트에서 `long` 은 `int` 보다 넓다 — `strtol` 이 성공해도 `INT_MAX`/`INT_MIN` 검사가 따로 필요하다.
