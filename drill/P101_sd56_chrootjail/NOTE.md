- 「[SD] SD56. 작업 디렉터리 변경 없는 chroot Jail 생성 — chdir 동반으로 치환」 — 시큐어코딩 체화 드릴 (회차 규칙 A/B/C, 변형 요구사항, 모범답안)
- 시큐어코딩가이드: Part 7. API 오용 — 3. 작업 디렉터리 변경 없는 chroot Jail 생성 (`CWE-243`)

**함정 요약**
- `chdir("/")`를 `chroot()` **이전에** 호출 — 순서가 바뀌면 아무 효과가 없다.
- `chroot()`만 있으면 격리가 끝난다고 생각 — 이 항목 전체가 "chroot는 절반의 격리"라는 걸 보여준다.
- SD06(경로 조작)에서 배운 `realpath` 접두어 검사를 이 항목에도 그대로 적용하면 끝이라고 생각 — 이 항목의 핵심은 경로 문자열 검증이 아니라 **작업 디렉터리 자체의 위치**다.

**한 줄 설명 연습**: "chdir 동반으로 치환" — 이 규칙을 내 말로 한 줄로 쓴다.
