# P005 · get_dirname — const 문자열은 자를 수 없다, 복사해서 잘라라

## 요구사항
경로 문자열 `path` 에서 **마지막 `/` 앞부분**(디렉터리 이름)을 `out` 에 만든다. 원본 `path` 는 절대 수정하지 않는다(리터럴일 수 있다).
- 마지막 `/` 가 맨 앞이면(`"/x"`, `"/"`) 결과는 `"/"`.
- `/` 가 하나도 없으면 실패.

## 시그니처
```c
int get_dirname(const char *path, char *out, size_t outsize);
/* 0  : 성공
 * -1 : 실패 — NULL, outsize == 0, '/' 없음, 결과(+NUL)가 outsize 에 안 들어감. 이때 out 은 건드리지 않는다 */
```

## 입출력 예시
| path | outsize | 반환 | out |
|---|---|---|---|
| `"/home/dir"` | 32 | 0 | `"/home"` |
| `"/home/dir/"` | 32 | 0 | `"/home/dir"` |
| `"/x"` | 32 | 0 | `"/"` |
| `"/"` | 32 | 0 | `"/"` |
| `"a/b"` | 32 | 0 | `"a"` |
| `"/home/dir"` | 6 | 0 | `"/home"` (딱 맞음) |
| `"/home/dir"` | 5 | -1 | (변화 없음) |
| `"file"`, `""`, `NULL` | 32 | -1 | (변화 없음) |

## 제약
- `path` 에 `'\0'` 을 쓰는 방식(`*slash = '\0'`)은 금지 — `const` 이고 리터럴일 수 있다. 위치(길이)만 구해 `memcpy` 로 복사.
- 정규화(`..`, `//`)는 하지 않는다. 마지막 `/` 기준.
- `out` 은 정확히 `outsize` 바이트 버퍼다.
