**함정 요약**
- `*slash = '\0'` 로 원본을 자르면 리터럴이 읽기 전용 영역이라 SIGSEGV (쓰기 금지 영역). 원본을 건드리지 않고 **출력 버퍼에 복사**한다.
- `len + 1 > outsize` — 널 문자 자리까지 확인하지 않으면 딱 맞는 크기에서 1바이트 넘친다.
- `"/x"` → 길이 0 의 빈 문자열이 되는 루트 케이스를 따로 처리해야 한다.
- `slash - path` 는 `ptrdiff_t` → `size_t` 로 캐스팅하기 전에 `slash != NULL` 을 확인.

**한 줄 설명 연습**: "입력 문자열은 읽기만 하고, 결과는 호출자가 준 버퍼에 크기 검사 후 복사한다."
