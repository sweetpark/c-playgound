# P075 · sd30 keylen — 충분하지 못한 키 길이 사용 — 최소 길이 상수 검증으로 치환

## 요구사항

암호화에 쓸 대칭키의 비트 수를 검증한다.
128비트 미만은 거부한다.

이미 `solution.c` 에 **Bad 함수가 들어 있다**(취약점을 먼저 관찰하세요). 같은 소재의 **Good 함수만 구현**한다. 치환 규칙: **최소 길이 상수 검증으로 치환**.

## 시그니처

```c
int validate_key_length_bad(int key_bits);
int validate_key_length_good(int key_bits);
```

## 입출력 예시

| `key_bits` | Bad 결과 | 이유 |
| :--- | :--- | :--- |
| 256 (정상) | 통과 | 충분한 길이 |
| 56(DES 수준) | **통과(취약)** | 검사 자체가 없다 |

## 제약

- Bad 함수와 `mock_*` 파일(있다면)은 수정하지 않는다. `solution.c` 의 Good 함수만 채운다.
- Bad 는 **실제로 뚫린다**는 것이 시험의 일부다(자식 프로세스로 실행). Good 은 같은 공격을 막고 정상 입력은 그대로 통과시켜야 한다(과잉 차단 금지).
- 경고 0, ASan/UBSan 0 (`-Wall -Wextra -Werror`).

## 통과 기준

`make P075` → `PASS` (실패 시 `FAIL k` 와 어긋난 항목 출력), 경고 0, ASan/UBSan 0. 힌트: `HINT1.md` → `HINT2.md`.

시험이 확인하는 것:

- Bad는 DES 수준의 56비트 키도 그대로 통과시켜야 한다(취약점 재현)
- Bad는 0비트도 통과시킨다
- Good은 56비트 키를 거부해야 한다
- Good은 64비트 키도 거부해야 한다
- Good은 128비트 키는 통과시켜야 한다(경계값)
- Good은 256비트 키도 통과시켜야 한다
