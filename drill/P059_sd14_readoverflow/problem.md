# P059 · sd14 readoverflow — 범위 초과해서 읽기 — 길이 동반 전달로 치환

## 요구사항

정수 배열과 인덱스를 받아 해당 위치의 값을 반환한다.
- 인덱스가 배열 크기를 벗어나면 안전하게 실패 처리해야 한다.

이미 `solution.c` 에 **Bad 함수가 들어 있다**(취약점을 먼저 관찰하세요). 같은 소재의 **Good 함수만 구현**한다. 치환 규칙: **길이 동반 전달로 치환**.

## 시그니처

```c
int read_at_index_bad(const int *arr, int idx);
int read_at_index_good(const int *arr, size_t size, int idx, int *out);
```

## 입출력 예시

| `idx` (배열 크기 3) | Bad 결과 | 이유 |
| :--- | :--- | :--- |
| 2 (정상) | 정상 값 반환 | 유효 인덱스(0~2) |
| 5 (범위 초과) | **힙 버퍼 오버리드로 크래시** | 배열 뒤 힙 메모리를 읽는다 — 다른 데이터·포인터 값이 새어나갈 수 있다 |

## 제약

- Bad 함수와 `mock_*` 파일(있다면)은 수정하지 않는다. `solution.c` 의 Good 함수만 채운다.
- Bad 는 **실제로 뚫린다**는 것이 시험의 일부다(자식 프로세스로 실행). Good 은 같은 공격을 막고 정상 입력은 그대로 통과시켜야 한다(과잉 차단 금지).
- 경고 0, ASan/UBSan 0 (`-Wall -Wextra -Werror`).

## 통과 기준

`make P059` → `PASS` (실패 시 `FAIL k` 와 어긋난 항목 출력), 경고 0, ASan/UBSan 0. 힌트: `HINT1.md` → `HINT2.md`.

시험이 확인하는 것:

- Bad는 배열 경계를 넘는 인덱스를 읽으면 크래시해야 한다(취약점 재현)
- 유효 인덱스는 크래시 없이 정상 동작해야 한다
- Good은 범위 밖 인덱스를 거부해야 한다
- 정상 인덱스는 성공해야 한다
- 읽은 값이 정확해야 한다
