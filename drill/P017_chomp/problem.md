# P017 · chomp — 개행은 있을 때만 지운다

## 요구사항
`fgets` 로 읽은 줄 끝의 **개행 하나**(`"\n"` 또는 `"\r\n"`)를 지운다. 개행이 없으면(버퍼가 꽉 차서 줄이 잘려 읽힌 경우) **아무것도 지우지 않는다**. 지운 뒤의 문자열 길이를 돌려준다.

## 시그니처
```c
size_t chomp(char *s);   /* 결과 strlen(s). s == NULL 이면 0 */
```

## 입출력 예시
| 입력 | 결과 | 반환 |
|---|---|---|
| `"abc\n"` | `"abc"` | 3 |
| `"abc"` | `"abc"` (마지막 글자를 지우면 안 됨) | 3 |
| `""` | `""` | 0 |
| `"abc\r\n"` | `"abc"` | 3 |
| `"a\r"` | `"a\r"` | 2 |
| `"ab\n\n"` | `"ab\n"` (끝의 하나만) | 3 |

## 제약
- `buf[strlen(buf) - 1] = '\0'` 금지 — 빈 문자열이면 `buf[-1]`, 개행이 없으면 멀쩡한 글자를 지운다.
- 정확히 `strlen+1` 바이트인 힙 버퍼에서도 범위 밖을 읽거나 쓰지 않는다(ASan).
