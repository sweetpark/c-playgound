# NOTE · P017 chomp (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[C] 파일 입출력 실습 — fopen·open 오류 패턴과 임시파일 + rename 안전 저장」 §1 "10-04-a 바이너리로 연 파일에 buf[strlen-1]=0", "10-04-b 입력이 버퍼보다 길면 마지막 글자를 잘못 지움"
- 소스: [`c_basic/lecture/fio/10-04-a.c`](../../c_basic/lecture/fio/10-04-a.c), [`10-04-b.c`](../../c_basic/lecture/fio/10-04-b.c)

**함정 요약**
- 개행 확인 없이 `buf[strlen-1] = 0` : 버퍼보다 긴 줄은 멀쩡한 마지막 글자를 지우고, 빈 문자열이면 `buf[-1]` 쓰기.
- CRLF 파일의 `\r` 처리. 바이너리로 연 파일은 개행을 믿지 말고 `fread` 와 바이트 수로.
- 반환값이 있으면 호출자가 `strlen` 을 다시 부르지 않아도 된다.

**한 줄 설명 연습**: "줄 끝을 지우기 전에 거기에 정말 개행이 있는지, 문자열이 비어 있지 않은지를 먼저 본다."
