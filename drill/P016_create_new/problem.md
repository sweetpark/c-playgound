# P016 · create_new — 있으면 덮어쓰지 않는다 (wx)

## 요구사항
`path` 에 **새 파일**을 만든다. 이미 있으면 **덮어쓰지 않고** "이미 있음" 으로 알린다. 존재 확인과 생성 사이에 다른 프로세스가 끼어들 수 없어야 한다.

## 시그니처
```c
int create_new(const char *path);
/* 0  : 새로 만들었다 (빈 파일)
 * 1  : 이미 존재한다 (내용 그대로)
 * -1 : 그 외 오류 (디렉터리 없음, 권한, path == NULL ...) */
```

## 입출력 예시
| 상황 | 반환 |
|---|---|
| 없는 파일 | 0 (생성됨) |
| 내용 `"keep"` 이 있는 파일 | 1, 내용은 `"keep"` 그대로 |
| 존재하지 않는 디렉터리 아래 | -1 |
| `NULL` | -1 |

## 제약
- `access()`/`stat()` 으로 확인한 뒤 `fopen("w")` 하는 방식은 금지(TOCTOU). 한 번의 호출로 "없을 때만 생성" 을 한다.
- "이미 있음" 과 "그 외 오류" 는 `errno` 로 구분한다. 열었으면 반드시 닫는다.
