- 문자 검사에 `isdigit(c)` 를 그냥 씀 — `char` 가 음수일 때 UB 다.
- 길이 검사를 `strlen` 결과로만 함 — 입력이 널 종단이 아닐 수 있다.
- 실패인데 `RET_FAIL` 하나로 뭉뚱그림 — 로그만 보고 원인을 못 찾는다.
- (C) 범위 검사를 형식 검사보다 먼저 함 — `21000229000000` 이 `NOT_SUPPORTED` 로 나온다.
- (C) `tm_year` / `tm_mon` 을 그대로 대입 — `tm_year` 는 `연 - 1900`, `tm_mon` 은 `월 - 1` 이다.
- (C) epoch 를 `int` / 32비트 `time_t` 로 계산 — 2038 경계에서 오버플로한다.
