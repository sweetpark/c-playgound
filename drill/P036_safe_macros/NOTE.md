# NOTE · P036 safe_macros (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[C] 종합본 — 안전한 C 코딩 체크리스트와 방어 매크로」
- 「[C] 동적 메모리 실습 — malloc·free 오류 패턴과 유연 배열 구조체 연결리스트」 §1 (FREE 매크로를 do-while(0) 로 정의하는 이유), §2 (XNEW/XNEWN, 타입 매크로)
- 관련: [`common/`](../../common/) 의 `mem.h`

**함정 요약**
- 블록(`{}`)으로 정의한 매크로 + `;` → `if/else` 에서 컴파일 에러(또는 의도와 다른 동작). 다중문 매크로는 `do { } while (0)`.
- `sizeof(포인터)` vs `sizeof(*포인터)` — 힙 오버플로의 단골 원인.
- 곱셈 오버플로를 검사하지 않는 `malloc(n * sizeof)`.
- 해제 직후 `NULL` 대입은 같은 포인터가 나중에 또 쓰일 때(두 번째 `free` 등) 의미가 있다.

**한 줄 설명 연습**: "해제와 할당은 NULL 대입·sizeof(*p)·오버플로 검사를 매크로 한 곳에 모아 매번 같은 방식으로 쓴다."
