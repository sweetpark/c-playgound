# P029 · be64 — 빅엔디안 64비트 변환

## 요구사항
64비트 정수를 **빅엔디안 8바이트**로 쓰고 읽는다(`htonll`/`ntohll` 직접 구현). 호스트 엔디안에 의존하지 않고 시프트로만 만든다.

## 시그니처
```c
void     put_be64(uint8_t out[8], uint64_t v);     /* out[0] 이 최상위 바이트. 8바이트만 쓴다 */
uint64_t get_be64(const uint8_t in[8]);
```

## 입출력 예시
| 값 | 바이트열 (out[0]…out[7]) |
|---|---|
| `0x0102030405060708` | `01 02 03 04 05 06 07 08` |
| `0xFF00000000000000` | `FF 00 00 00 00 00 00 00` |
| `0x8000000000000001` | `80 00 00 00 00 00 00 01` |
| `0xDEADBEEF` | `00 00 00 00 DE AD BE EF` |
| `UINT64_MAX` | `FF` × 8 |

## 제약
- 구조체/정수를 통째로 `memcpy` 하지 않는다(호스트 엔디안이 새어 나온다).
- `in[0] << 56` 처럼 **`int` 로 승격된 값**을 시프트하면 폭 초과(UB). 먼저 `uint64_t` 로 올린다. UBSan 이 잡는다.
- 마스크와 시프트의 순서: `(v >> k) & 0xFF`. 바이트별 이동량 56, 48, …, 0 을 표로 검산.

## 통과 기준
`make P029` → `PASS n/n`, 경고 0, ASan/UBSan 0. 힌트: `HINT1.md` → `HINT2.md`.
