# NOTE · P099 sd54 dnstrust (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[SD] SD54. DNS lookup에 의존한 보안결정 — IP 화이트리스트로 치환」 — 시큐어코딩 체화 드릴 (회차 규칙 A/B/C, 변형 요구사항, 모범답안)
- 시큐어코딩가이드: Part 7. API 오용 — 1. DNS lookup에 의존한 보안결정 (`CWE-247`)

**함정 요약**
- "도메인명 화이트리스트도 화이트리스트 아닌가"라고 생각 — 화이트리스트에 무엇을 넣는지가 아니라, **그 값을 어떻게 얻었는지**가 핵심이다.
- Bad를 고치면서 `gethostbyname()` 호출을 아예 없애지 않고 결과만 다르게 씀 — DNS 조회 자체가 신뢰 경계를 넘나드는 지점이다.
- IP 화이트리스트면 완전히 안전하다고 믿음 — 변형 C에서 짚었듯 IP도 스푸핑·BGP 하이재킹 등으로 위조될 수 있다.

**한 줄 설명 연습**: "IP 화이트리스트로 치환" — 이 규칙을 내 말로 한 줄로 쓴다.
