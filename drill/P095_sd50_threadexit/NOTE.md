# NOTE · P095 sd50 threadexit (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[SD] SD50. 코드정확성 스레드 조기 종료 — join 또는 detach 명시로 치환」 — 시큐어코딩 체화 드릴 (회차 규칙 A/B/C, 변형 요구사항, 모범답안)
- 시큐어코딩가이드: Part 5. 코드 오류 — 8. 코드 정확성: 스레드 조기 종료 (`CWE-730`)

**함정 요약**
- "메인 스레드가 곧 종료되니 상관없다"고 판단 — 짧게 끝나는 프로그램에서는 우연히 문제가 안 드러나지만, 장시간 도는 서버 프로세스에서 요청마다 스레드를 생성하면 미회수 스레드가 계속 쌓여 결국 스레드 생성 자체가 실패하는 지점에 도달한다
- `pthread_join`과 `pthread_detach`를 동시에 호출 — 이미 detach된 스레드를 join하려고 하면 정의되지 않은 동작이다.
- 결과를 기다릴 필요가 없다는 이유로 아예 아무 것도 안 함(Bad) — "기다릴 필요가 없다"는 "회수할 필요가 없다"가 아니다.

**한 줄 설명 연습**: "join 또는 detach 명시로 치환" — 이 규칙을 내 말로 한 줄로 쓴다.
