# P027 · run_squares — 스레드 인자의 수명과 join

## 요구사항
`n` 개의 스레드를 만들어 스레드 `i` 가 `out[i] = i * i` 를 계산하게 하고, **모두 join** 한 뒤 돌아온다. 각 스레드는 **자기 번호를 정확히** 받아야 한다 — 루프 변수의 주소를 그대로 넘기면 안 된다.

## 시그니처
```c
int run_squares(int n, long *out);
/* 0  : 성공 (out[0..n-1] = i*i)
 * -1 : n <= 0, n > 64, out == NULL, 스레드 생성 실패 (이미 만든 스레드는 join) */
```

## 입출력 예시
| `n` | 결과 |
|---|---|
| 1 | `out[0] = 0` |
| 8 | `0, 1, 4, 9, 16, 25, 36, 49` |
| 64 | `out[63] = 3969` |
| 0, -3, 65, `out == NULL` | -1 (out 불변) |

## 제약
- `pthread_create(&t, NULL, f, &i)` 처럼 **지역/루프 변수의 주소**를 넘기면 스레드가 읽는 시점에 값이 바뀌거나 함수가 이미 끝나 있다.
- 스레드마다 별도의 인자 객체(배열의 자기 칸, 또는 힙에 만들어 스레드가 `free`)를 준다. 힙이라면 누수 0.
- 만든 스레드는 모두 `join` 한다(만들다 실패해도).
