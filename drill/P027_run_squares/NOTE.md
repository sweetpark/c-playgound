**함정 요약**
- 스레드 인자의 수명이 호출 함수보다 짧으면 안 된다. 지역 변수 주소를 넘기고 함수가 먼저 끝나면 `Result: 1` 이 `0` 으로 출력된다.
- 루프 변수 `i` 의 주소를 모든 스레드에 주면 스레드가 도는 사이 `i` 가 바뀐다 (200 회 반복 테스트가 이걸 잡는다).
- `join`(또는 `detach`) 중 하나만. join 을 빠뜨리면 main 이 끝나 결과가 사라지고, detach 한 스레드를 join 하면 오류.

**한 줄 설명 연습**: "스레드에 넘기는 인자는 스레드가 끝날 때까지 살아 있고 스레드마다 따로여야 한다."
