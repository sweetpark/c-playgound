# P056 · sd11 stackoverflow — 스택 버퍼 오버플로우 — 길이 검사 후 strncpy로 치환

## 요구사항

외부에서 받은 문자열을 24바이트 지역 버퍼에 복사하는 함수를 만든다.
- 입력이 버퍼보다 길면 안전하게 실패 처리해야 한다.
- 버퍼 안 문자열은 항상 널로 끝나야 한다.

이미 `solution.c` 에 **Bad 함수가 들어 있다**(취약점을 먼저 관찰하세요). 같은 소재의 **Good 함수만 구현**한다. 치환 규칙: **길이 검사 후 strncpy로 치환**.

신뢰 경계:

| 값 | 출처 | 검증 없이 흘러가는 곳 |
| :--- | :--- | :--- |
| `input` | 외부(함수 인자) | 24바이트 스택 지역 버퍼로의 복사 |

## 시그니처

```c
void manipulate_string_bad(const char *input);
int manipulate_string_good(const char *input, char *out, size_t out_size);
```

## 입출력 예시

| 입력 길이 | Bad 결과 | 이유 |
| :--- | :--- | :--- |
| 5자 (정상) | 정상 동작 | 버퍼 크기 이내 |
| 41자 (24바이트 초과) | **스택 버퍼 오버플로우로 크래시** | `strcpy` 가 버퍼 경계를 넘어 인접 스택 영역(반환주소 포함)을 덮는다 |

## 제약

- Bad 함수와 `mock_*` 파일(있다면)은 수정하지 않는다. `solution.c` 의 Good 함수만 채운다.
- Bad 는 **실제로 뚫린다**는 것이 시험의 일부다(자식 프로세스로 실행). Good 은 같은 공격을 막고 정상 입력은 그대로 통과시켜야 한다(과잉 차단 금지).
- 경고 0, ASan/UBSan 0 (`-Wall -Wextra -Werror`).
