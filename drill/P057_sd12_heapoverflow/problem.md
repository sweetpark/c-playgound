# P057 · sd12 heapoverflow — 힙 버퍼 오버플로우 — 길이 검사 후 strncpy로 치환

## 요구사항

`malloc()` 으로 10바이트 힙 버퍼를 만들고 외부 문자열을 복사한다.
- 입력이 버퍼보다 길면 실패로 처리한다.

이미 `solution.c` 에 **Bad 함수가 들어 있다**(취약점을 먼저 관찰하세요). 같은 소재의 **Good 함수만 구현**한다. 치환 규칙: **길이 검사 후 strncpy로 치환**.

## 시그니처

```c
void heap_copy_bad(const char *input);
int heap_copy_good(const char *input, char **out);
```

## 입출력 예시

| 입력 길이 | Bad 결과 | 이유 |
| :--- | :--- | :--- |
| 5자 (정상) | 정상 동작 | 버퍼 크기 이내 |
| 32자 (10바이트 초과) | **힙 버퍼 오버플로우로 크래시** | 인접 힙 청크의 메타데이터(size·fd·bk)가 덮인다 |

## 제약

- Bad 함수와 `mock_*` 파일(있다면)은 수정하지 않는다. `solution.c` 의 Good 함수만 채운다.
- Bad 는 **실제로 뚫린다**는 것이 시험의 일부다(자식 프로세스로 실행). Good 은 같은 공격을 막고 정상 입력은 그대로 통과시켜야 한다(과잉 차단 금지).
- 경고 0, ASan/UBSan 0 (`-Wall -Wextra -Werror`).

## 통과 기준

`make P057` → `PASS` (실패 시 `FAIL k` 와 어긋난 항목 출력), 경고 0, ASan/UBSan 0. 힌트: `HINT1.md` → `HINT2.md`.

시험이 확인하는 것:

- Bad는 10바이트를 넘는 입력에서 힙 오버플로우로 크래시해야 한다(취약점 재현)
- 짧은 입력은 크래시 없이 정상 동작해야 한다
- Good은 버퍼보다 긴 입력을 거부해야 한다
- 정상 입력은 성공해야 한다
- 복사된 내용이 정확해야 한다
