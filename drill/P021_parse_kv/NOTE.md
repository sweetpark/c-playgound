# NOTE · P021 parse_kv (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[C] 문자열 함수 실습 — strncpy·strncat 직접 구현과 오버플로 함정」 "교육자료 추가 과제 (8-7) — parse_kv, read_line"
- 관련: P005 (const 문자열은 복사해서 자른다), P006 (read_line)

**함정 요약**
- 공백 제거를 위해 원본에 널 문자를 쓰는 습관 → 리터럴이면 SIGSEGV.
- 버퍼 경계: 길이가 `size-1` 이면 들어가고 `size` 이면 오류. 두 경계를 모두 시험한다.
- 에러 경로마다 `key/val` 초기화를 빠뜨리기 쉽다 → 함수 시작에서 한 번.
- `kl + 1 > key_size` 를 `kl > key_size - 1` 로 쓰면 `key_size == 0` 에서 언더플로 (그래서 먼저 -1).

**한 줄 설명 연습**: "입력 문자열은 위치(포인터 범위)로만 다루고, 검증이 다 끝난 뒤에 출력 버퍼에 복사한다."
