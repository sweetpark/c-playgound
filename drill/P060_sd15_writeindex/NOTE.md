# NOTE · P060 sd15 writeindex (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[SD] SD15. 검사되지 않은 배열 인덱싱 — 하한·상한 동시 검사로 치환」 — 시큐어코딩 체화 드릴 (회차 규칙 A/B/C, 변형 요구사항, 모범답안)
- 시큐어코딩가이드: Part 1-3. 메모리 경계 계열 — 15. 검사되지 않은 배열 인덱싱 (`CWE-129`)

**함정 요약**
- 상한만 검사하고 `num <= 0` (하한)을 빼먹음 — PDF 원문 예시(`sizes[num-1]=size`)의 실제 결함이 이것이다 — `num` 이 0이면 `arr[-1]`, 음수면 더 먼 곳에 쓴다
- `num > arr_size` 로만 비교(경계값 처리 오류) — `num == arr_size` 는 유효한 값(`arr[arr_size-1]`)인데 `>` 대신 `>=` 를 잘못 써서 정상 케이스까지 막을 수 있다.
- `arr_size` 를 `int` 로 받고 `num` 과 부호 있는 비교만 함 — `(size_t)num > arr_size` 형태로 캐스팅해 비교해야, `num` 이 매우 큰 `int` 값일 때도 정확히 비교된다

**한 줄 설명 연습**: "하한·상한 동시 검사로 치환" — 이 규칙을 내 말로 한 줄로 쓴다.
