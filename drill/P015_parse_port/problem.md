# P015 · parse_port — strtoul 은 "-1" 을 받아들인다

## 요구사항
10진 문자열 `s` 를 포트 번호(1~65535)로 변환해 `*out` 에 저장한다. 문자열 전체가 숫자여야 한다.
부호(`+`, `-`)·공백·0x 접두는 허용하지 않는다. 실패하면 `*out` 은 건드리지 않는다.

## 시그니처
```c
int parse_port(const char *s, unsigned short *out);
/* 0 : 성공   /   -1 : 모든 실패 (NULL, 형식 오류, 범위 밖) */
```

## 입출력 예시
| `s` | 반환 | `*out` |
|---|---|---|
| `"80"`, `"1"`, `"65535"`, `"080"` | 0 | 80, 1, 65535, 80 |
| `"0"`, `"65536"` | -1 | (변화 없음) |
| `"-1"` | -1 | (변화 없음) — `strtoul` 은 이걸 큰 양수로 바꾼다 |
| `"+80"`, `" 80"`, `"80x"`, `""`, `"0x50"` | -1 | (변화 없음) |
| `"99999999999999999999999"` | -1 | (ERANGE) |
| `"4294967376"` | -1 | 2³²+80 을 `unsigned int` 로 자르면 80 이 되어 통과해 버림 |

## 제약
- `strtoul` 을 쓰되, 호출 전 `errno = 0`, 끝 포인터 검사, 범위 검사(`1..65535`)를 직접.
- 결과를 `unsigned short` 로 줄이는 변환은 **범위 검사를 끝낸 뒤에만**.
- 첫 글자가 숫자인지 먼저 확인하면 부호·공백이 한 번에 걸러진다(`isdigit((unsigned char)c)`).
