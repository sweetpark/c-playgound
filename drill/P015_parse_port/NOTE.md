- 소스: [`c_basic/err/my_atoi.c`](../../c_basic/err/my_atoi.c)

**함정 요약**
- `strtoul("-1")` → `ULONG_MAX` (오류 없음). 부호 없는 변환은 음수 입력을 래핑한다.
- 큰 타입에서 작은 타입으로 자르는 캐스트(`(unsigned short)v`, `(unsigned int)v`)는 범위 검사 **이후**에만.
- `v == 0` 이 "실패" 인지 "0" 인지는 반환값만으로 알 수 없다 — 끝 포인터와 errno 로 판단.
- 이런 입력 검증 실수가 SD17~SD19(정수 오버플로·부호 변환) 시큐어코딩 드릴과 같은 뿌리다.

**한 줄 설명 연습**: "부호 없는 변환은 음수를 에러 없이 큰 양수로 바꾸니까, 변환 전에 형식을, 변환 후에 범위를 확인한다."
