# NOTE · P006 read_line (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[C] 문자열 함수 실습 — strncpy·strncat 직접 구현과 오버플로 함정」 §4 "8-05-b: 입력 길이를 검사하지 않는다" 와 "교육자료 추가 과제 (8-7)" 의 `read_line` 요구사항
- 소스: [`c_basic/lecture/str/8-05-b.c`](../../c_basic/lecture/str/8-05-b.c)

**함정 요약**
- 길이 상한 없는 `*p++ = ch` 루프, 그리고 마지막 `*p++ = 0` 도 범위를 넘을 수 있다.
- `fgetc/getchar` 결과는 `int` 로 받아 `EOF` 와 비교. `char` 에 담으면 `0xFF` 바이트가 EOF 와 같아져 줄이 일찍 끊긴다(또는 `unsigned char` 환경에서는 EOF 를 못 알아본다).
- 잘린 줄의 나머지를 소비하지 않으면 다음 `read_line` 이 줄 중간부터 읽는다.
- 딱 `size - 1` 글자인 줄(잘림 아님)과 `size` 글자인 줄(잘림)의 경계.

**한 줄 설명 연습**: "입력 루프는 상한과 EOF 를 둘 다 조건에 두고, 널 문자 자리를 항상 한 칸 남긴다."
