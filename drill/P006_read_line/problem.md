# P006 · read_line — 길이 상한이 있는 한 줄 읽기

## 요구사항
`fgetc` 로 한 줄을 읽어 `buf`(크기 `size`)에 담는다. 개행은 저장하지 않는다. `buf` 는 **어떤 경우에도 널 종료**.
줄이 `size - 1` 글자보다 길면 담을 수 있는 만큼만 담고, **나머지는 읽어서 버린다**(다음 줄에 섞이지 않게). 마지막 줄에 개행이 없어도 정상이다.

## 시그니처
```c
int read_line(FILE *fp, char *buf, size_t size);
/* 0  : 정상 (줄 전체가 들어감)
 * 1  : 줄이 잘림 (나머지는 소비됨)
 * -1 : 문자를 하나도 못 읽고 EOF  (buf = "")
 * -2 : 인자 오류 (fp/buf == NULL, size == 0) */
```

## 입출력 예시 (size = 5)
| 입력 스트림 | 반환 | buf | 다음 호출 |
|---|---|---|---|
| `"abc\n"` | 0 | `"abc"` | -1 |
| `"1234\n"` | 0 | `"1234"` | -1 |
| `"12345\nnext\n"` | 1 | `"1234"` | 0, `"next"` |
| `"end"` (개행 없음) | 0 | `"end"` | -1 |
| `"\n"` | 0 | `""` | -1 |
| `""` | -1 | `""` | |

## 제약
- 반환값을 받는 변수는 `int` (`fgetc` 는 `int` 를 돌려준다. `char` 에 담으면 0xFF 바이트가 EOF 로 오인된다).
- `buf[size..]` 는 절대 쓰지 않는다. `size == 1` 이면 문자를 담을 자리가 없다(널 문자만).
- `getchar` 대신 `fgetc(fp)` 를 쓰는 것만 원본 실습과 다르다(테스트에서 임시 파일을 읽기 위해).
