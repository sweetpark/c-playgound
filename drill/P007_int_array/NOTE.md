**함정 요약**
- `malloc` 은 초기화하지 않는다 — 테스트에서는 우연히 0 이라 통과하고 운영에서만 깨지기 쉽다.
- `malloc(n * sizeof(int))` 의 곱셈이 래핑되면 작은 버퍼가 할당되고 이후 쓰기는 힙 오버플로.
- `malloc(0)` 은 구현 정의(NULL 일 수도, 유일 포인터일 수도) — `NULL` 이면 실패라는 판정이 틀린다.
- 해제 후 `NULL` 대입은 "같은 포인터를 나중에 또 쓸 수 있을 때" 의미가 있다 (double free 방지).

**한 줄 설명 연습**: "크기는 `size_t` 로 받아 곱하기 전에 검사하고, 읽기 전에 반드시 채우며, 해제하면 포인터를 `NULL` 로 둔다."
