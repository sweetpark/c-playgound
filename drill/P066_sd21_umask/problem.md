# P066 · sd21 umask — 중요한 자원에 대한 잘못된 권한허용 — 최소 권한 umask로 치환

## 요구사항

설정 파일을 생성할 때 파일 권한을 설정한다.
- 소유자만 읽고 쓸 수 있어야 한다(`0600`).

이미 `solution.c` 에 **Bad 함수가 들어 있다**(취약점을 먼저 관찰하세요). 같은 소재의 **Good 함수만 구현**한다. 치환 규칙: **최소 권한 umask로 치환**.

## 시그니처

```c
int create_file_bad(const char *path);
int create_file_good(const char *path);
```

## 입출력 예시

| umask 설정 | 실제 생성 권한(`open(..., 0666)` 기준) | 위험 |
| :--- | :--- | :--- |
| `umask(0)` | **`0666`(rw-rw-rw-)** | 같은 시스템의 다른 계정이나 침투한 저권한 프로세스가 읽고 쓸 수 있다 |
| `umask(077)` | `0600`(rw-------) | 소유자만 접근 가능 |

## 제약

- Bad 함수와 `mock_*` 파일(있다면)은 수정하지 않는다. `solution.c` 의 Good 함수만 채운다.
- Bad 는 **실제로 뚫린다**는 것이 시험의 일부다(자식 프로세스로 실행). Good 은 같은 공격을 막고 정상 입력은 그대로 통과시켜야 한다(과잉 차단 금지).
- 경고 0, ASan/UBSan 0 (`-Wall -Wextra -Werror`).

- Good은 소유자만 읽고 쓸 수 있는 권한(0600)으로 생성해야 한다
