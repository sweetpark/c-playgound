# NOTE · P058 sd13 writebeforestart (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[SD] SD13. 버퍼 시작 지점 이전에 쓰기 — 하한 검사로 치환」 — 시큐어코딩 체화 드릴 (회차 규칙 A/B/C, 변형 요구사항, 모범답안)
- 시큐어코딩가이드: Part 1-3. 메모리 경계 계열 — 13. 버퍼 시작 지점 이전에 쓰기 (`CWE-124`)

**함정 요약**
- 루프 시작 전에 `count > arr_size` 만 검사하고 끝냄 — 이 항목의 취약점은 "인덱스가 반복 중에 감소하다가" 발생한다.
- 상한 검사(SD15)와 하한 검사(이 항목)를 혼동해서 `>=` 방향을 반대로 씀 — "감소 인덱스는 하한", "증가 인덱스는 상한"이라는 방향 감각을 반사적으로 연결한다
- `int` 대신 `size_t` 로 인덱스를 선언 — `size_t` 는 부호 없는 타입이라 `wordIndex--` 가 0에서 한 번 더 감소하면 거대한 양수(랩어라운드)가 되어 오히려 더 위험해진다.

**한 줄 설명 연습**: "하한 검사로 치환" — 이 규칙을 내 말로 한 줄로 쓴다.
