# P076 · sd31 weakrandom — 적절하지 않은 난수 값의 사용 — 커널 CSPRNG로 치환

## 요구사항

32자 16진수 세션 토큰을 생성한다.
- 토큰은 예측 불가능해야 한다.
- 난수 생성에 실패하면 반드시 에러를 반환해야 한다(약한 값으로 대체 금지).

이미 `solution.c` 에 **Bad 함수가 들어 있다**(취약점을 먼저 관찰하세요). 같은 소재의 **Good 함수만 구현**한다. 치환 규칙: **커널 CSPRNG로 치환**.

## 시그니처

```c
void gen_token_bad(unsigned seed, char *out, size_t out_size);
int gen_token_good(char *out, size_t out_size);
```

## 입출력 예시

| 상황 | Bad 결과 | 이유 |
| :--- | :--- | :--- |
| 같은 seed로 두 번 생성 | **완전히 같은 토큰** | `rand()` 는 seed가 같으면 항상 같은 시퀀스를 낸다(예측 가능) |
| 매번 새로 생성(Good) | 매번 다른 토큰 | 커널 CSPRNG는 내부 엔트로피 풀에서 뽑는다 |

## 제약

- Bad 함수와 `mock_*` 파일(있다면)은 수정하지 않는다. `solution.c` 의 Good 함수만 채운다.
- Bad 는 **실제로 뚫린다**는 것이 시험의 일부다(자식 프로세스로 실행). Good 은 같은 공격을 막고 정상 입력은 그대로 통과시켜야 한다(과잉 차단 금지).
- 경고 0, ASan/UBSan 0 (`-Wall -Wextra -Werror`).

## 통과 기준

`make P076` → `PASS` (실패 시 `FAIL k` 와 어긋난 항목 출력), 경고 0, ASan/UBSan 0. 힌트: `HINT1.md` → `HINT2.md`.

시험이 확인하는 것:

- Bad는 같은 seed면 항상 같은 토큰을 만들어야 한다(예측 가능함 = 취약점 재현)
- 적어도 seed가 다르면 결과도 달라진다(그래도 예측 가능한 건 여전함)
- 정상 크기 버퍼는 성공해야 한다
- 두 번째 호출도 성공해야 한다
- Good은 매 호출마다 다른 토큰을 만들어야 한다(진짜 난수원을 쓴다는 증거)
- Good은 버퍼가 너무 작으면 실패로 알려야 한다
