# NOTE · P061 sd16 nullterm (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[SD] SD16. 널 종료 문제 — 길이 명시 복사와 수동 종료로 치환」 — 시큐어코딩 체화 드릴 (회차 규칙 A/B/C, 변형 요구사항, 모범답안)
- 시큐어코딩가이드: Part 1-3. 메모리 경계 계열 — 16. 널 종료 문제 (`CWE-170`)

**함정 요약**
- 테스트에서 `raw` 를 스택 배열(`char raw[8]`)로만 두고 `malloc(8)` 을 안 씀 — 스택 배열은 컴파일러가 여유 공간이나 다른 지역변수를 바로 뒤에 둘 수 있어 ASan이 항상 정확히 잡아주지 못할 때가 있다.
- Good에서 실패(`-1`) 시 `out` 을 아예 안 건드림 — 호출자가 실패를 무시하고 `out` 을 문자열로 쓰면 초기화 안 된 메모리를 읽는 또 다른 버그가 생긴다.
- `raw_len` 을 아예 안 받고 `strlen(raw)` 로 길이를 구하려 함 — 이 항목의 전제 자체가 "raw는 널 종료가 안 되어 있다"는 것이다.

**한 줄 설명 연습**: "길이 명시 복사와 수동 종료로 치환" — 이 규칙을 내 말로 한 줄로 쓴다.
