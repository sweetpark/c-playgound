**함정 요약**
- 두 번째·세 번째 할당이 실패했을 때 첫 번째 블록을 해제하지 않고 `return -1` — 에러 경로 누수의 전형. 정상 경로만 테스트하면 절대 안 보인다(그래서 이 테스트는 N 번째 `malloc` 을 일부러 실패시킨다).
- 정리 코드가 경로마다 흩어지면 하나를 빼먹는다 → `NULL` 로 시작 + 정리 구간 한 곳, 순서는 획득의 역순.
- 중간에 `*out` 을 먼저 채우면 실패 시 호출자가 반쯤 만든 객체를 갖게 된다.
- `errno` 가 필요하면 실패 직후에 저장(정리 중 `free` 가 바꿀 수 있음).

**한 줄 설명 연습**: "획득한 자원마다 NULL 로 시작하고 실패하면 한 곳으로 점프해서 역순으로 푼다."
