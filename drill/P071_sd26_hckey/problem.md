# P071 · sd26 hckey — 하드코드된 암호화 키 — 키 저장소 주입으로 치환

## 요구사항

DB 암호화에 쓸 16바이트 AES 키를 가져온다.
- 키는 필요할 때 교체할 수 있어야 한다(rotation).

이미 `solution.c` 에 **Bad 함수가 들어 있다**(취약점을 먼저 관찰하세요). 같은 소재의 **Good 함수만 구현**한다. 치환 규칙: **키 저장소 주입으로 치환**.

## 시그니처

```c
const unsigned char *get_key_bad(void);
int get_key_good(const char *key_name, unsigned char *out, size_t out_len);
```

| 상황 | Bad 결과 | 이유 |
| :--- | :--- | :--- |
| 몇 번을 호출해도 | **완전히 같은 키(같은 주소, 같은 바이트)** | 키가 소스 상수라 절대 안 바뀐다 |

## 제약

- Bad 함수와 `mock_*` 파일(있다면)은 수정하지 않는다. `solution.c` 의 Good 함수만 채운다.
- Bad 는 **실제로 뚫린다**는 것이 시험의 일부다(자식 프로세스로 실행). Good 은 같은 공격을 막고 정상 입력은 그대로 통과시켜야 한다(과잉 차단 금지).
- 경고 0, ASan/UBSan 0 (`-Wall -Wextra -Werror`).

## 통과 기준

`make P071` → `PASS` (실패 시 `FAIL k` 와 어긋난 항목 출력), 경고 0, ASan/UBSan 0. 힌트: `HINT1.md` → `HINT2.md`.

시험이 확인하는 것:

- Bad는 언제 호출해도 완전히 같은 키를 반환해야 한다(교체 불가능함 = 취약점 재현)
- v1 키 로드는 성공해야 한다
- v2 키 로드는 성공해야 한다
- Good은 키 이름만 바꾸면 완전히 다른 키를 가져올 수 있어야 한다(키 교체 가능함을 증명)
- Good은 등록되지 않은 키 이름은 실패로 알려야 한다
