# NOTE · P090 sd45 signconv (풀고 난 뒤에 보세요)

**원본 글** (읽기 전용, 여기에 복사하지 않음)
- 「[SD] SD45. 부호 정수를 무부호 정수로 타입 변환 오류 — 안전한 에러값으로 치환」 — 시큐어코딩 체화 드릴 (회차 규칙 A/B/C, 변형 요구사항, 모범답안)
- 시큐어코딩가이드: Part 5. 코드 오류 — 3. 부호 정수를 무부호 정수로 타입 변환 오류 (`CWE-195`)

**함정 요약**
- `return -1`을 `return (unsigned int)0 - 1`로 바꿔서 "고쳤다"고 착각 — 표현만 바뀌었을 뿐 값은 여전히 `UINT_MAX`다.
- 호출자 쪽에서 `(int)len_bad(s) == -1`로 검사하려 함 — 함수가 이미 `unsigned int`를 반환하기로 계약했는데 호출자가 다시 `int`로 캐스팅해 검사하는 건 임시방편이다.
- "이 값이 인덱스나 길이로 쓰이지 않으니 상관없다"고 넘김 — 지금 안 쓰여도 나중에 다른 코드가 이 반환값을 경계 검사나 메모리 크기로 재사용할 수 있다.

**한 줄 설명 연습**: "안전한 에러값으로 치환" — 이 규칙을 내 말로 한 줄로 쓴다.
